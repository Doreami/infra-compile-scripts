# 测试报告模板

每次测试完成后，在 `YYYY-MM-DD/` 下存放：

| 文件 | 说明 |
|------|------|
| `性能测试报告_YYYY-MM-DD.md` | 耗时对比、EXPLAIN、SQL、加速比 |
| `火焰图分析报告_YYYY-MM-DD.md` | 热点函数、模块归类、SIFT vs GIST 对比 |
| `性能优化分析_YYYY-MM-DD.md` | 基于测试结果的三层/四层代码优化分析（由分析 session 产出） |
| `flamegraphs/` | 火焰图 SVG + 原始 perf data（perf_data/ 不提交 git） |

> 模板一、二覆盖性能测试报告和火焰图分析报告。模板三（性能优化分析）见 `性能优化分析_2026-07-17.md` 作为参考。

**通用规范**：
- 报告顶部必须包含**版本信息表**（所有相关组件的 commit SHA）
- 耗时测试记录**建索引耗时**（用 `nohup` + `time` 包装避免 SSH 超时丢失）
- 火焰图采集前确认 `perf` 和 FlameGraph 脚本可用

## 四、测试方法

- 耗时来源: `EXPLAIN (ANALYZE)` 的 `Total runtime`
- 每组跑 3 次取平均（IVF 第一轮冷启动不计入）
- 查询向量用字面量常量（子查询阻止索引匹配）
- 全扫: `enable_indexscan=off, enable_bitmapscan=off, enable_vectorsearch=off`
- IVF: `enable_vectorsearch=on, try_vector_engine_strategy=force`

# 生成流程

1. **采集数据**
   ```bash
   # 耗时基准
   # 手动跑 EXPLAIN (ANALYZE) 3 轮，每场景记录 Total runtime
   
   # 火焰图
   bash run_flamegraph.sh
   ```

2. **收集版本信息**
   ```bash
   for d in ~/iceberg-og/{openGauss-server-datainfra,iceberg-rust-bridge,iceberg-index,iceberg-rust-cache,iceberg-rust-datainfra,openGauss-Catalog,iceberg_fdw,iceberg_delta}; do
     echo "$(basename $d): $(git -C $d log --oneline -1)"
   done
   ```

3. **收集 perf report 数据**
   ```bash
   cd YYYY-MM-DD/flamegraphs/perf_data
   for f in perf_*.data; do
     echo "=== $(basename $f .data) ==="
     perf report -i "$f" --stdio --percent-limit 0.5 --no-children | head -20
   done
   ```

4. **深入排查索引函数**
   ```bash
   perf report -i perf_ivf_k10_*.data --stdio --percent-limit 0.1 \
     | grep libiceberg_rust_bridge | grep -v "parquet::"
   ```

5. **填写两份报告**：拷贝模板 → 填入数据 → 写关键发现 → 提优化建议

6. **提交**
   ```bash
   git add 端到端性能测试/
   git commit -m "perf: 性能测试 + 火焰图采集 YYYY-MM-DD"
   git push
   ```
