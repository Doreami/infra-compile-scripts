# Iceberg 向量索引性能测试方案

## 测试目标

用 SIFT1M（100 万条 128 维向量）对比**无索引全表扫描** vs **HNSW 索引扫描**的性能差异。

## 测试环境

- 数据集: ANN_SIFT1M（sift_base.fvecs, 1M × 128d float）
- 查询集: sift_query.fvecs（10K × 128d）
- Ground Truth: sift_groundtruth.ivecs（10K × top-100）
- 索引类型: HNSW（M=16/32/64, efConstruction=200/500）
- 测试维度: Recall@K (K=1,10,100), QPS, 构建时间, 索引大小

## 准备步骤

### 1. 解压 SIFT 数据集

```bash
tar xzf sift.tar.gz -C ~/infra-compile-scripts/端到端性能测试/
# 得到: sift_base.fvecs, sift_query.fvecs, sift_groundtruth.ivecs, sift_learn.fvecs
```

### 2. 生成 Parquet 数据

```bash
GAUSSHOME=~/iceberg-og/openGauss-server-datainfra/mppdb_temp_install
export ICEBERG_WAREHOUSE=file://$HOME/warehouse
python3 convert_sift.py --input ~/infra-compile-scripts/端到端性能测试/ --warehouse $ICEBERG_WAREHOUSE --namespace sift_ns --table sift1m
```

### 3. 创建表和索引

```bash
$GAUSSHOME/bin/gsql -p 37000 -d postgres -f create_table.sql
```

## 测试用例

### 用例 B1: 无索引 — 全表扫描（Baseline）

```sql
-- 不走索引，强制全表扫描
SET enable_indexscan = off;
EXPLAIN (ANALYZE, TIMING OFF)
SELECT id FROM sift_ns.sift1m
ORDER BY vec <-> '{query_vector}'::vector
LIMIT 10;
```

### 用例 B2: HNSW 索引 — M=16, efConstruction=200

```sql
-- 创建索引
SELECT iceberg_catalog.create_index(
    'sift_ns', 'sift1m', 'idx_hnsw_16_200',
    '["vec"]'::jsonb, 'hnsw', 'hnsw',
    '{"M":16,"efConstruction":200,"distance":"l2"}'::jsonb
);

-- 查询
EXPLAIN (ANALYZE, TIMING OFF)
SELECT id FROM sift_ns.sift1m
ORDER BY vec <-> '{query_vector}'::vector
LIMIT 10;
```

## 评估指标

| 指标 | 说明 | 获取方式 |
|------|------|---------|
| Recall@1 | Top-1 是否命中真实最近邻 | Python 脚本计算 |
| Recall@10 | Top-10 中命中真实 Top-10 的比例 | Python 脚本计算 |
| Recall@100 | Top-100 召回率 | Python 脚本计算 |
| QPS | 每秒查询数 | 10K 查询总耗时 / 10000 |
| 索引构建时间 | create_index 耗时 | \timing |
| 索引大小 | 磁盘占用 | du -sh |

## 预期结果

| 配置 | Recall@10 | QPS | 构建时间 | 索引大小 |
|------|-----------|-----|---------|---------|
| 无索引（全表扫描） | 1.000 | 极低 | 0 | 0 |
| HNSW M=16 efC=200 | >0.95 | 高于全扫 100x+ | ~分钟级 | ~200MB |
| HNSW M=32 efC=500 | >0.98 | 稍低于 M=16 | ~分钟级 | ~400MB |
| HNSW M=64 efC=500 | >0.99 | 低于 M=32 | ~分钟级 | ~600MB |
