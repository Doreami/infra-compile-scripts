# 火焰图采集与分析工作流

## 快速开始

```bash
# 1. 采集火焰图（默认场景：fullscan K10/K100/K1000 + IVF K10/K100/K10000）
cd ~/infra-compile-scripts/端到端性能测试
python3 run_flamegraph.py --serial --namespace sift_ns --table sift1m

# 2. 同步到本地
scp -P 10021 "xl@140.210.239.53:~/infra-compile-scripts/端到端性能测试/YYYY-MM-DD/flamegraphs/*.svg" ./YYYY-MM-DD/flamegraphs/
scp -P 10021 "xl@140.210.239.53:~/infra-compile-scripts/端到端性能测试/YYYY-MM-DD/flamegraphs/perf_data/*.data" ./YYYY-MM-DD/flamegraphs/perf_data/

# 3. 获取 perf report 并生成分析报告
ssh xl@server "perf report -i ~/infra-compile-scripts/端到端性能测试/YYYY-MM-DD/flamegraphs/perf_data/perf_{prefix}_{scenario}.data --stdio --percent-limit 0.5 --no-children"
```

## 参数说明

| 参数 | 必填 | 默认 | 说明 |
|------|:--:|------|------|
| `--namespace` | ✓ | — | 命名空间 |
| `--table` | ✓ | — | 表名 |
| `--dataset` | — | 同 --table | 输出文件前缀 |
| `--serial` | — | 否 | 串行模式，跳过 DOP 场景 |
| `--scenarios` | — | 默认场景 | 逗号分隔 |
| `--query-file` | — | 无 | 查询向量文件，不传则取表中 id=1 |
| `--query-format` | — | 自动推断 | fvecs / hdf5 |

## 默认场景

```
fullscan_k10, fullscan_k100, fullscan_k1000,
ivf_k10, ivf_k100, ivf_k10000
```

| 场景 | 轮数 | SQL |
|------|:--:|------|
| fullscan_k10 | 2 | `SET enable_vectorsearch=off` + `LIMIT 10` |
| fullscan_k100 | 2 | `SET enable_vectorsearch=off` + `LIMIT 100` |
| fullscan_k1000 | 2 | `SET enable_vectorsearch=off` + `LIMIT 1000` |
| ivf_k10 | 5 | `SET enable_vectorsearch=on` + `LIMIT 10` |
| ivf_k100 | 3 | `SET enable_vectorsearch=on` + `LIMIT 100` |
| ivf_k10000 | 2 | `SET enable_vectorsearch=on` + `LIMIT 10000` |

## 性能计时

```bash
gsql=~/iceberg-og/openGauss-server-datainfra/mppdb_temp_install/bin/gsql
QVEC=$($gsql -d postgres -p 37000 -t -A -c "SELECT vec FROM {ns}.{table} WHERE id=1;")

# 预热
$gsql -d postgres -p 37000 -c "SET enable_vectorsearch=on; SELECT id FROM {ns}.{table} ORDER BY vec <-> '${QVEC}'::vector LIMIT 10;" > /dev/null

# 计时（墙钟法）
for i in 1 2 3 4 5; do
  s=$(date +%s%3N)
  $gsql -d postgres -p 37000 -c "SET enable_vectorsearch=on; SELECT id FROM {ns}.{table} ORDER BY vec <-> '${QVEC}'::vector LIMIT 10;" > /dev/null
  e=$(date +%s%3N)
  echo "run$i: $((e-s))ms"
done
```

## sterror 验证文件打开数

```bash
PID=$(pgrep -x gaussdb | head -1)
strace -f -e openat -p $PID -o /tmp/strace.log &
sleep 0.5
$gsql -d postgres -p 37000 -c "SELECT * FROM {ns}.{table} WHERE id=1;" > /dev/null
sleep 0.5
kill $! 2>/dev/null

echo "unique files: $(grep -oP '\.parquet' /tmp/strace.log | sort -u | wc -l)"
echo "total opens: $(grep -c parquet /tmp/strace.log)"
```

## 生成报告

报告模板包含以下章节：

### 火焰图分析报告

1. **测试条件**：数据集、维度、索引配置、查询向量来源
2. **测试场景**：各场景的轮数和样本数
3. **Top 函数对比**：IVF / FullScan 各自的 CPU 热点（来自 `perf report --no-children`）
4. **按模块分布**：内核 I/O、bridge、gaussdb 各自的占比
5. **关键结论**：与历史基线对比、维度影响、瓶颈分析
6. **火焰图清单**：SVG 文件列表

### 性能分析报告

1. **当前性能**：IVF / FullScan 耗时 + 加速比
2. **与历史基线对比**：逐版本追踪，区分基线优化和专项优化
3. **优化项贡献分析**：各优化项的预估贡献比例
4. **IVF vs FullScan 分析**：时间分布分解
5. **跨数据集对比**：SIFT / GIST 的差异和比值

## 常见问题

**火焰图 579 字节（空图）**：`pgrep -f gaussdb` 匹配到 bash wrapper，改用 `pgrep -x gaussdb`。

**SIFT IVF 火焰图样本太少**：查询太快（<300ms），增加轮数或减少 perf sleep 时间。

**perf 权限不足**：`echo -1 > /proc/sys/kernel/perf_event_paranoid` 或用 root。
