# 脚本说明

## 数据导入

### `setup_fixed.py` — 数据导入（主要使用）

一次性完成建表、导数据、建索引。支持 fvecs 和 HDF5。

```bash
# 无分区表
python3 setup_fixed.py --input ~/测试文件/sift_base.fvecs
python3 setup_fixed.py --input ~/测试文件/gist-960-euclidean.hdf5

# 分区表（并行测试用）
python3 setup_fixed.py --input ~/测试文件/sift_base.fvecs --partition-buckets 16
```

| 参数 | 默认值 | 说明 |
|------|------|------|
| `--input` | 必填 | 数据文件 |
| `--namespace` | 自动推断 | 如 `sift_ns`，分区加 `_part` |
| `--table` | 自动推断 | 如 `sift1m`，分区加 `_part` |
| `--partition-buckets` | 0 | >0 建分区表 |
| `--num-clusters` | 256 | IVFPQ 聚类数 |
| `--compression` | `uncompressed` | Parquet 压缩 |

### `setup_s3.py` — S3 数据导入

与 `setup_fixed.py` 用法相同，但写入 S3/MinIO 存储。详见 [S3测试指南.md](S3测试指南.md)。

```bash
python3 setup_s3.py --input ~/测试文件/sift_base.fvecs --compression uncompressed
```

需要 S3 server 级选项配好后才能使用（FDW warehouse + 端点 + 凭证）。

## 查询测试

### 获取查询向量

和 `run_flamegraph.py` 一致，从查询向量集中取第一条：

```bash
# SIFT: 从 sift_query.fvecs 读取第一条查询向量
python3 -c "
import struct
with open('$HOME/测试文件/sift_query.fvecs','rb') as f:
    data = f.read()
dim = struct.unpack_from('<i', data, 0)[0]
qv = ','.join(str(v) for v in struct.unpack_from(f'<{dim}f', data, 4))
print(f'[{qv}]')
"

# GIST: 从 HDF5 的 test 数据集读取第一条查询向量
python3 -c "
import h5py
with h5py.File('$HOME/测试文件/gist-960-euclidean.hdf5','r') as f:
    qv = ','.join(str(v) for v in f['test'][0].tolist())
print(f'[{qv}]')
"
```

### 手动墙钟法

```bash
TABLE=gist_ns.gist1m_none
# 把上面 python3 输出的向量值粘贴到 QVEC
QVEC='[0.0459,0.0439,...]'

cat > /tmp/q.sql << EOF
SET enable_vectorsearch=on;  -- IVF
SELECT id FROM ${TABLE} ORDER BY vec <-> '${QVEC}'::vector LIMIT 10;
EOF

# 预热
gsql -d postgres -p 37000 -f /tmp/q.sql > /dev/null 2>&1
# 3 轮计时
for i in 1 2 3; do
  s=$(date +%s%3N)
  gsql -d postgres -p 37000 -f /tmp/q.sql > /dev/null 2>&1
  e=$(date +%s%3N)
  echo "run$i: $((e-s))ms"
done
```

## 火焰图

### `run_flamegraph.py` — 自动采集

```bash
# 默认场景（不指定 --scenarios）
python3 run_flamegraph.py --serial --namespace sift_ns --table sift1m
python3 run_flamegraph.py --serial --dataset gist --namespace gist_ns --table gist1m

# 自定义场景
python3 run_flamegraph.py --serial --namespace sift_ns --table sift1m --scenarios ivf_k10,ivf_k100

# 指定查询向量文件（不指定则自动取表中 id=1）
python3 run_flamegraph.py --serial --namespace sift_ns --table sift1m \
    --query-file ~/测试文件/sift_query.fvecs --query-format fvecs
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `--namespace` | 必填 | 命名空间 |
| `--table` | 必填 | 表名 |
| `--dataset` | 同 --table | 输出前缀，如 `sift` / `gist` |
| `--serial` | 否 | 串行模式（跳过 `_dop*` 并行场景） |
| `--scenarios` | 见默认场景 | 逗号分隔 |
| `--query-file` | 无 | 查询向量文件（.fvecs / .hdf5） |
| `--query-format` | 自动推断 | `fvecs` / `hdf5` |
| `--query-dataset` | `test` | hdf5 格式的 dataset 名 |
| `--query-index` | `0` | hdf5 格式的行索引 |

**默认场景（串行）**：`fullscan_k10, fullscan_k100, fullscan_k1000, ivf_k10, ivf_k100, ivf_k10000`

**查询向量来源**（优先级）：
1. `--query-file` 指定文件 → 从文件读取
2. 未指定 → `SELECT vec FROM {table} WHERE id=1`

> `pgrep -x gaussdb` 精确匹配二进制名，避免匹配到 bash wrapper。

### 手动采集

```bash
PID=$(pgrep -x gaussdb)
# 预热
gsql -d postgres -p 37000 -f /tmp/q.sql > /dev/null 2>&1
sleep 2
# 录制
perf record -F 99 -g -p $PID -o /tmp/perf.data -- sleep 999 &
PFPID=$!; sleep 1.5
# 跑 3 轮
for i in 1 2 3; do gsql -d postgres -p 37000 -f /tmp/q.sql > /dev/null 2>&1; done
# 停止
kill -TERM $PFPID; wait $PFPID
# 生成 SVG
perf script -i /tmp/perf.data | ~/FlameGraph/stackcollapse-perf.pl | ~/FlameGraph/flamegraph.pl --title "GIST IVF K=10" --width 1200 > ~/flame.svg
```

### perf stat 缺页分析

```bash
PID=$(pgrep -x gaussdb)
perf stat -e page-faults,task-clock -p $PID -- gsql -d postgres -p 37000 -f /tmp/q.sql
```

## 常用操作速查

```bash
# 环境
source ~/iceberg-og/opengauss.env
gsql=~/iceberg-og/openGauss-server-datainfra/mppdb_temp_install/bin/gsql

# 获取查询向量（从标准查询集，非表中数据）
python3 -c "import h5py; f=h5py.File('$HOME/测试文件/gist-960-euclidean.hdf5','r'); print('['+','.join(str(v) for v in f['test'][0].tolist())+']')"

# 查看索引状态
$gsql -d postgres -p 37000 -c "SELECT table_name,index_name,index_type,index_status FROM iceberg_catalog.table_indexes WHERE namespace='gist_ns';"

# 删表（先删外表再删内部表）
$gsql -d postgres -p 37000 -c "DROP FOREIGN TABLE IF EXISTS gist_ns.gist1m_none;"
$gsql -d postgres -p 37000 -c "SELECT iceberg_catalog.drop_table('gist_ns','gist1m_none');"

# 查表行数
$gsql -d postgres -p 37000 -c "SELECT count(*) FROM gist_ns.gist1m_none;"
```
