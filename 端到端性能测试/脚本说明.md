## 数据导入

### `setup_fixed.py`

```bash
python3 setup_fixed.py --input ~/测试文件/sift_base.fvecs
python3 setup_fixed.py --input ~/测试文件/sift_base.fvecs --partition-buckets 32
python3 setup_fixed.py --input ~/测试文件/base.1B.fbin --namespace deep_ns --table deep1b --chunk-size 1000000 --partition-buckets 32
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--input` | 必填 | `.fvecs` / `.hdf5` / `.fbin` |
| `--namespace` | 自动推断 | |
| `--table` | 自动推断 | |
| `--chunk-size` | 50000 | 每批写入行数 |
| `--partition-buckets` | 0 | >0 创建 `bucket(id, N)` 分区 |
| `--vec-type` | `list` | `list`=list<float>, `fixed`=fixed binary |
| `--compression` | `uncompressed` | Parquet 压缩 |
| `--max-rows` | None | 截取行数 |

## 性能测试

### `bench_complete.py` — 完整测试

```bash
# 全量
python3 bench_complete.py --all --output results.json

# 单表，指定 K/DOP
python3 bench_complete.py --dataset sift --k 10,100 --dop 1,8

# 跳过 FullScan（大数据集）
python3 bench_complete.py --dataset deep --skip-fullscan --skip-recall
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--dataset` | — | `sift` / `gist` / `deep` / `synth` |
| `--all` | — | 四表全测 |
| `--k` | `10,100,1000,10000` | K 值 |
| `--dop` | `1,2,4,8` | DOP 值 |
| `--skip-ivf` | 否 | 跳过 IVF |
| `--skip-fullscan` | 否 | 跳过 FullScan |
| `--skip-recall` | 否 | 跳过召回率 |
| `--rounds` | 3 | 测试轮数 |
| `--warmup` | 1 | 预热轮数 |
| `--output` | `/tmp/bench_complete_results.json` | 输出路径 |
| `--query-idx` | 0 | Query 向量索引 |

### `bench_parallel.py` — DOP 并行测试

```bash
python3 bench_parallel.py --dataset sift --dop 1,2,4,8
```

## 火焰图

### `flame_comprehensive.sh` — 批量火焰图采集

```bash
# 需先启动 gaussdb，不要 source opengauss.env（会污染 perf 环境）
bash flame_comprehensive.sh
```

### 手动采集

```bash
PID=$(pgrep -u $USER -x gaussdb)
perf record -F 99 -g -p $PID -o /tmp/perf.data -- sleep 999 &
PFPID=$!; sleep 1
for i in 1 2 3; do
  ~/iceberg-og/.../bin/gsql -d postgres -p 37000 -f /tmp/q.sql > /dev/null
done
kill $PFPID; wait $PFPID
perf script -i /tmp/perf.data | ~/FlameGraph/stackcollapse-perf.pl | ~/FlameGraph/flamegraph.pl --title "label" --width 1200 > flame.svg
```
