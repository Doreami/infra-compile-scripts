# 简介

import_csv.py是一个能给opengauss导入数据的脚本



## 提前安装

需要提前安装python导入数据的一些模块

```shell
pip3 install --user pyiceberg pyarrow numpy -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple --trusted-host mirrors.tuna.tsinghua.edu.cn
pip3 install --user sqlalchemy -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple --trusted-host mirrors.tuna.tsinghua.edu.cn
```



## 提前执行

```sql
-- 1. 创建extension
CREATE EXTENSION iceberg_fdw;
CREATE EXTENSION iceberg_catalog;
CREATE SERVER iceberg_catalog_server FOREIGN DATA WRAPPER iceberg_fdw;

-- 2. 创建存储目录 (待优化可自动创建)
mkdir ~/warehouse
```



# 创建表

## 命令参考

```shell
# 部分字段可能不需要填
python3 import_csv.py --op create --csv test_data1.csv  \
-n test_ns -t users \
-c "id:long,name:string,score:double,vec:vector(5)" \
-w ~/warehouse --gsql "gsql -d postgres -p 37000"
```
